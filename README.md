# Контакт-трекер

Приложение для iPhone (React Native + Expo), которое работает с контактной книгой телефона:

- показывает список контактов и подсвечивает тех, с кем вы давно не общались;
- позволяет ставить рейтинг контактам (1–5 звёзд);
- фиксирует дату последнего общения кнопкой «связался сегодня» (доступа к истории звонков/SMS у сторонних приложений на iOS нет, поэтому дата отмечается вручную);
- даёт быстрые действия: позвонить, написать SMS, написать email;
- хранит заметки по контакту;
- позволяет удалить контакт из адресной книги.

Данные о рейтинге, заметках и датах последнего общения хранятся локально на устройстве (AsyncStorage), сами контакты не покидают телефон.

## Запуск

```bash
npm install
npx expo start
```

Откройте приложение на iPhone через **Expo Go** (отсканировав QR-код) — Mac и Xcode для этого не нужны.

Для полноценной сборки под App Store потребуется EAS Build:

```bash
npx eas build --platform ios
```

## Структура

- `App.tsx` — навигация (список контактов → карточка контакта)
- `src/lib/contacts.ts` — чтение контактов через `expo-contacts`
- `src/lib/store.ts` — локальное хранилище рейтингов/заметок/дат (AsyncStorage)
- `src/screens/ContactsListScreen.tsx` — список, поиск, сортировка «давно не общались»
- `src/screens/ContactDetailScreen.tsx` — карточка контакта: звонок/SMS/email, рейтинг, заметки, удаление
